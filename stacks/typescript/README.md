# The TypeScript stack

Distilled from Suite Builder (G-020, G-083, G-086, G-239, G-242, G-251, G-254, G-290). Stamping a
TypeScript project copies `starter/` to the repository root (a `starter/` path below is the same path at a stamped project's root) and writes `stacks/typescript/PRESENT`;
`scripts/gate.sh` then runs `stacks/typescript/gate.sh`.

| Rule | What it is | Held by |
| --- | --- | --- |
| Toolchain | Node LTS; npm 11 or newer (`engines.npm` `>=11` with `engine-strict=true` in `.npmrc`; the gate refuses an older major in one line: npm 10 crashes on vitest 4's peer set); `npm ci` only; `ignore-scripts=true` in `.npmrc` (a package that truly needs its install script is allow-listed in `theGhost.md` by name and why); `moduleResolution` is `NodeNext` when the product runs on Node and `Bundler` when it is bundled for a browser (imports then go through a path alias); a session container has no Docker daemon, so nothing the fast loop needs may run in one; LF everywhere (`.gitattributes`: CRLF broke byte-for-byte goldens on Windows) | `.npmrc`, `package.json`, `.gitattributes`, `gate.sh` |
| Fast loop | `npx vitest run --project unit`, under 30 s; browsers, real sites and the Java half of any generated output are their own project, run by the gate; unit tests import no `node:` module (they are `test/unit/**/*.test.ts`; the starter ships none, the project writes the first), so a script that needs `node:` is a `.mjs` file under `scripts/`; of the starter's three, `mutate.mjs` and `cooldown.mjs` are run under node by `test/test_stacks.py` (Core's, carried into the stamp, in the Python fast loop when node is present) and `weakened.mjs` has no test | `vitest.config.ts` |
| Dependencies | `package-lock.json` only; a new dependency needs a one-line reason in `theGhost.md` and Ghost's approval; a high or critical advisory stops the gate (`npm audit --audit-level=high`) | `gate.sh` |
| Cooldown | no locked version younger than 7 days: each version the lock brings that `origin/main` did not hold is looked up on the registry (`starter/scripts/cooldown.mjs`); no list of exceptions, the answer is to wait or take the version before; with no `package-lock.json` yet it prints that and exits 1 under `--strict`. The founding lockfile is all new against `origin/main`, so the cooldown refuses every transitive version published in the last 7 days: each is pinned to the version before by `overrides` in `package.json`, and each override is listed in `docs/HANDOFF.md` for removal at a tune-up once its version is past the cooldown (removed, it comes in by `docs/DEPENDENCY-REVIEW.md` like any update) | `gate.sh` |
| Mutation | Stryker with the **command runner** (its vitest runner silently tested nothing after the first pass; the first scores were fake, G-290), one source file per run, `src/**` only (`scripts/*.mjs` are not mutated), each mutant one `vitest run` of the tests that import the file; every survivor killed or written up in `docs/MUTATION.md`; a file's report is cached under a key over every byte that can change its verdict, and `--no-cache`, `MUTATE_CACHE=0` or the cold gate's `GHOST_COLD=1` (`scripts/gate.sh` exports it) bypasses the cache, so the cold run is the full run (`docs/when/tune-up.md` step 2); a test that the runner catches a mutant it is known to catch | `stryker.config.mjs`, `gate.sh` |
| Readability | a function is named for what it holds; no abstraction before its second use (G-020); `knip` so nothing floats (no unused export, file or dependency); the working set (a file plus its direct imports, comments excluded) under its token budget, hubs under theirs (G-242, optional ratchet) | `knip.json`, `gate.sh` |
| Weakened tests | `scripts/weakened.mjs` lists removed assertions, `skip`/`only`, and exact matchers loosened, against `origin/main`; it never fails, and the commit says why the test was wrong | the gate's output |
| Generated | `*.gen.ts` and generated docs marked `linguist-generated -diff`; each has a regeneration command and a staleness test (AGT-05) | `.gitattributes` |
| Dependency updates | `docs/DEPENDENCY-REVIEW.md` (C-035). Fetch both sides without running anything: `npm pack <name>@<version> --ignore-scripts --silent` into a new empty folder, then `python3 -I scripts/review_scan.py --unpack old.tgz new.tgz "$REVIEW"` (it unpacks with the safe flags, lists links and special files and never follows them; never `tar -x` by hand); list every package the change brings in by `npm install --package-lock-only --ignore-scripts` and a lockfile diff; the audit is `npm audit` and `npm audit signatures`; provenance is `npm view <name>@<version> dist.attestations.provenance.predicateType` and `_npmUser.name` compared with the version before; `scripts/cooldown.mjs` is the cooldown | `scripts/review_scan.py`, `scripts/cooldown.mjs`, `docs/REVIEWED-VERSIONS.md` |
